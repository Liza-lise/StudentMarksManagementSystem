# Student Marks Management System

A web-based **Student Marks Management System** developed using **C# and ASP.NET Core MVC**. This application is designed to simplify the management of student academic records and marks through an organized web interface.

## Overview

The Student Marks Management System provides a foundation for managing student information and academic performance. It is developed using the Model-View-Controller (MVC) architecture, making the application structured, maintainable, and easy to extend.

## Features

- Web-based application built with ASP.NET Core MVC.
- Organized MVC architecture.
- Student management functionality.
- Academic marks management.
- User-friendly web interface.
- Structured project organization.

## Technologies Used

- **Programming Language:** C#

## Getting Started

### Prerequisites

Make sure you have installed:

- [.NET SDK](https://dotnet.microsoft.com/download)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/liza-lise/StudentMarksManagementSystem.git
```

2. Navigate into the project folder:

```bash
cd StudentMarksManagementSystem
```

3. Restore dependencies:

```bash
dotnet restore
```

4. Build the application:

```bash
dotnet build
```

5. Run the application:

```bash
dotnet run
```

6. Open the local URL displayed in your terminal in your web browser.

## Running in Visual Studio Code

Open the project folder in VS Code, open the integrated terminal, and execute:

```bash
dotnet restore
dotnet build
dotnet run
```
